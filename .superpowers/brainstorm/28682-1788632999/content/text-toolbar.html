固定兩行：上行切換類，下行下拉類

A

一行，橫向 scroll

所有控制排成一行，多出嘅撥過去。iOS Notes 嘅做法。

好處

  • 最慳位，canvas 露出最多
  • 實作最簡單

代價

  • 後面嘅控制「唔存在」——用戶唔知要撥
  • 顏色、字級呢啲要再彈嘢，一行入面彈唔落
B

一行常用 + 「Aa」推開面板（建議）

一行淨係放五個：粗體、斜體、底線、link、variable。「Aa」撳落去鍵盤位置換成一個面板：字級、顏色、對齊、list、刪除線、清除格式。再撳一下或者撳返文字就收返鍵盤。Google Docs app 就係咁。

好處

  • 常用嘅一撳即到，唔常用嘅全部有位、唔使撥
  • 面板有位放顏色格、字級選項，唔使再彈第三層
  • 同 block 動作列「Style」用同一個面板機制，一套 code

代價

  • 多一下切換（Aa）先到顏色
  • 面板同鍵盤互換要做得順（唔可以閃）
C

固定兩行

上行係切換類（粗斜底線 link variable），下行係下拉類（顏色、字級、對齊、list）。

好處

  • 全部一眼見晒，冇隱藏

代價

  • 兩行加鍵盤，canvas 剩返三分一，打字時見唔到上下文
  • 下行嘅下拉仍然要彈嘢，喺鍵盤上面彈好逼

共同假設：右上角變「Done」收鍵盤同退出文字編輯；退出後底部變返 block 動作列。
